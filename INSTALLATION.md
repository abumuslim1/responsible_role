# Инструкция по установке модуля Responsible Role

## Требования

- **Bitrix24**: Коробочная версия (Self-Hosted) или облачная версия
- **PHP**: 7.0 или выше
- **MySQL**: 5.5 или выше
- **Права администратора**: Для установки модуля требуются права администратора

## Способ 1: Установка через административную панель (рекомендуется)

### Шаг 1: Подготовка файлов модуля

1. Скачайте архив с модулем `responsible_role.zip`
2. Распакуйте архив
3. Убедитесь, что структура папок соответствует описанной в README

### Шаг 2: Загрузка модуля на сервер

#### Для коробочной версии (Self-Hosted):

1. Подключитесь к серверу по FTP или SSH
2. Перейдите в директорию модулей:
   ```
   /home/Bitrix/www/bitrix/modules/
   ```
3. Загрузите папку `responsible_role` в эту директорию
4. Убедитесь, что права доступа установлены правильно:
   ```bash
   chmod -R 755 /home/Bitrix/www/bitrix/modules/responsible_role/
   ```

#### Для облачной версии:

1. Перейдите в административную панель Bitrix24
2. Откройте **Администрирование → Модули и расширения → Модули**
3. Нажмите **"Загрузить модуль"**
4. Выберите архив `responsible_role.zip`
5. Нажмите **"Загрузить"**

### Шаг 3: Установка модуля

1. Откройте административную панель Bitrix24
2. Перейдите в **Администрирование → Модули и расширения → Модули**
3. Найдите модуль **"Responsible Role for Tasks"** в списке
4. Нажмите кнопку **"Установить"** рядом с модулем
5. Подождите завершения установки
6. Вы должны увидеть сообщение об успешной установке

### Шаг 4: Проверка установки

1. Откройте раздел **Задачи и проекты → Настройки → Права доступа**
2. Убедитесь, что в списке ролей появилась новая роль **"Ответственный"**
3. Откройте форму создания новой задачи
4. Убедитесь, что появилось новое поле **"Ответственный сотрудник"**

## Способ 2: Ручная установка через PHP

### Шаг 1: Загрузка файлов модуля

```bash
# Подключитесь к серверу по SSH
ssh user@your-server.com

# Перейдите в директорию модулей
cd /home/Bitrix/www/bitrix/modules/

# Загрузите файлы модуля
# (используйте FTP или другой метод загрузки)

# Установите права доступа
chmod -R 755 responsible_role/
```

### Шаг 2: Запуск скрипта установки

Создайте файл `install_module.php` в корне Bitrix:

```php
<?php
// /home/Bitrix/www/install_module.php

define("B_PROLOG_INCLUDED", true);
define("ADMIN", true);

require_once($_SERVER["DOCUMENT_ROOT"] . "/bitrix/modules/main/include/prolog_admin.php");

// Подключить модуль
$result = RegisterModule('responsible_role');

if ($result) {
    echo "Модуль успешно установлен";
} else {
    echo "Ошибка при установке модуля";
}

require_once($_SERVER["DOCUMENT_ROOT"] . "/bitrix/modules/main/include/epilog_admin.php");
?>
```

Затем откройте в браузере:
```
http://your-bitrix-site.com/install_module.php
```

## Решение проблем

### Проблема: Модуль не появляется в списке модулей

**Решение:**
1. Проверьте, что папка модуля находится в правильной директории
2. Убедитесь, что файл `module.php` присутствует в корне папки модуля
3. Проверьте права доступа на файлы (должны быть 755 или 644)
4. Очистите кэш Bitrix:
   ```bash
   rm -rf /home/Bitrix/www/bitrix/cache/*
   ```

### Проблема: Ошибка при установке модуля

**Решение:**
1. Проверьте логи Bitrix:
   ```bash
   tail -f /home/Bitrix/www/bitrix/modules/responsible_role/error.log
   ```
2. Убедитесь, что у пользователя веб-сервера есть права на запись в директорию модуля
3. Проверьте, что PHP имеет достаточно памяти (минимум 128 МБ)

### Проблема: Новое поле не появляется в форме задачи

**Решение:**
1. Очистите кэш браузера (Ctrl+F5)
2. Очистите кэш Bitrix
3. Проверьте, что кастомное поле создано в базе данных
4. Перезагрузите страницу задачи

### Проблема: Ошибка доступа к базе данных

**Решение:**
1. Проверьте, что таблица `b_responsible_role_mapping` создана
2. Убедитесь, что пользователь MySQL имеет права на создание и изменение таблиц
3. Проверьте соединение с базой данных в файле конфигурации Bitrix

### Проблема: REST API методы не работают

**Решение:**
1. Убедитесь, что модуль правильно установлен
2. Проверьте, что файл `rest_api.php` загружается при инициализации модуля
3. Убедитесь, что у пользователя есть права на использование REST API
