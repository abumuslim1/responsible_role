# Bitrix24 Module: Responsible Role

## Описание

Модуль добавляет новую роль **"Ответственный"** в систему задач Bitrix24 с полной интеграцией в бэкенд и фронтенд. Модуль позволяет:

- Добавить новую роль "Ответственный" с правами как у роли "Наблюдатель"
- Выбирать ответственного сотрудника при создании и редактировании задачи
- Отображать ответственного сотрудника в открытой задаче
- Фильтровать задачи по ответственному сотруднику

## Возможности

### Бэкенд функциональность

- **Создание роли**: Автоматическое создание роли "Ответственный" с правами наблюдателя при активации модуля
- **Кастомное поле**: Добавление поля `UF_RESPONSIBLE_EMPLOYEE` для выбора сотрудника
- **База данных**: Таблица `b_responsible_role_mapping` для хранения связей между задачами и ответственными сотрудниками
- **REST API**: Полный набор API методов для работы с ответственными сотрудниками
- **Обработчики событий**: Интеграция с событиями Bitrix24 для автоматического управления данными

### Фронтенд функциональность

- **Поле выбора**: Интерактивное поле для выбора ответственного сотрудника в форме задачи
- **Отображение**: Вывод информации об ответственном в деталях задачи
- **Фильтрация**: Фильтр по ответственному сотруднику в списке задач
- **Стили**: Профессиональные CSS стили для всех компонентов

## Установка

### Требования

- Bitrix24 (коробочная версия или облачная)
- PHP 7.0 или выше
- MySQL 5.5 или выше

### Процесс установки

1. Скопируйте папку `responsible_role` в директорию модулей Bitrix24:
   ```
   /home/Bitrix/www/bitrix/modules/responsible_role/
   ```

2. Перейдите в административную панель Bitrix24

3. Откройте раздел **Администрирование → Модули и расширения → Модули**

4. Найдите модуль **"Responsible Role for Tasks"** и нажмите **"Установить"**

5. После установки модуль будет активирован и готов к использованию

## Использование

### Добавление ответственного при создании задачи

1. Откройте форму создания новой задачи
2. В поле **"Ответственный сотрудник"** выберите нужного сотрудника из списка
3. Заполните остальные поля задачи
4. Нажмите **"Сохранить"**

### Редактирование ответственного в существующей задаче

1. Откройте задачу
2. Нажмите **"Редактировать"**
3. Измените значение в поле **"Ответственный сотрудник"**
4. Нажмите **"Сохранить"**

### Фильтрация задач по ответственному

1. Откройте список задач
2. В фильтре выберите **"Ответственный сотрудник"**
3. Выберите нужного сотрудника
4. Нажмите **"Применить фильтр"**

### Просмотр информации об ответственном

1. Откройте задачу
2. В разделе **"Ответственный"** будет отображена информация о выбранном сотруднике:
   - Имя и фамилия
   - Email адрес

## REST API

### Методы

#### 1. Получить ответственного для задачи
```
Метод: responsible_role.task.getResponsible
Параметры: taskId (обязательный)
Возвращает: Информацию об ответственном сотруднике
```

Пример:
```javascript
BX24.callMethod(
    'responsible_role.task.getResponsible',
    { taskId: 123 },
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log(result.data());
        }
    }
);
```

#### 2. Установить ответственного для задачи
```
Метод: responsible_role.task.setResponsible
Параметры: taskId, userId
Возвращает: Результат операции
```

Пример:
```javascript
BX24.callMethod(
    'responsible_role.task.setResponsible',
    { taskId: 123, userId: 456 },
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log('Ответственный установлен');
        }
    }
);
```

#### 3. Получить задачи по ответственному
```
Метод: responsible_role.task.getByResponsible
Параметры: userId (обязательный)
Возвращает: Список ID задач
```

Пример:
```javascript
BX24.callMethod(
    'responsible_role.task.getByResponsible',
    { userId: 456 },
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log(result.data().tasks);
        }
    }
);
```

#### 4. Получить статистику по ответственному
```
Метод: responsible_role.task.getStats
Параметры: userId (обязательный)
Возвращает: Статистику по задачам
```

Пример:
```javascript
BX24.callMethod(
    'responsible_role.task.getStats',
    { userId: 456 },
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            var stats = result.data().stats;
            console.log('Всего задач: ' + stats.TOTAL_TASKS);
            console.log('Активных: ' + stats.ACTIVE_TASKS);
            console.log('Завершено: ' + stats.COMPLETED_TASKS);
        }
    }
);
```

#### 5. Получить список всех пользователей
```
Метод: responsible_role.user.getList
Параметры: нет
Возвращает: Список всех активных пользователей
```

Пример:
```javascript
BX24.callMethod(
    'responsible_role.user.getList',
    {},
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log(result.data().users);
        }
    }
);
```

#### 6. Удалить ответственного из задачи
```
Метод: responsible_role.task.deleteResponsible
Параметры: taskId (обязательный)
Возвращает: Результат операции
```

Пример:
```javascript
BX24.callMethod(
    'responsible_role.task.deleteResponsible',
    { taskId: 123 },
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log('Ответственный удален');
        }
    }
);
```

## Обработчики событий

Модуль регистрирует следующие обработчики событий:

- **OnTaskAdd**: При создании новой задачи
- **OnTaskUpdate**: При обновлении задачи
- **OnTaskDelete**: При удалении задачи
- **OnTaskListDisplay**: При отображении списка задач
- **OnTaskDetailDisplay**: При отображении деталей задачи
- **OnTaskFilter**: При применении фильтра к задачам
- **OnUserDelete**: При удалении пользователя

## Права доступа

Роль **"Ответственный"** имеет следующие права (как у роли "Наблюдатель"):

- **Просмотр задач**: Да
- **Добавление комментариев**: Да
- **Редактирование задач**: Нет
- **Удаление задач**: Нет

## Удаление модуля

1. Перейдите в административную панель Bitrix24

2. Откройте раздел **Администрирование → Модули и расширения → Модули**

3. Найдите модуль **"Responsible Role for Tasks"** и нажмите **"Удалить"**

4. Подтвердите удаление

При удалении модуля будут удалены:
- Роль "Ответственный"
- Кастомное поле "Ответственный сотрудник"
- Все данные из таблицы `b_responsible_role_mapping`
