# Структура модуля Responsible Role

## Обзор структуры

Модуль Responsible Role организован следующим образом:

```
responsible_role/
├── install.php                  # Скрипт установки модуля
├── uninstall.php                # Скрипт удаления модуля
├── module.php                   # Регистрация модуля в Bitrix24
├── index.php                    # Главный файл модуля
├── class.php                    # Основной класс помощника
├── events.php                   # Обработчики событий
├── rest_api.php                 # REST API методы
├── step.php                     # Страница успешной установки
├── unstep.php                   # Страница успешного удаления
├── README.md                    # Основная документация
├── INSTALLATION.md              # Инструкции по установке
├── EXAMPLES.md                  # Примеры использования
├── CHANGELOG.md                 # История изменений
├── STRUCTURE.md                 # Этот файл
├── lang/                        # Локализация
│   ├── en/
│   │   └── module.php           # Английская локализация
│   └── ru/
│       └── module.php           # Русская локализация
├── js/                          # JavaScript файлы
│   └── responsible_role.js      # Основной JavaScript компонент
├── css/                         # CSS стили
│   └── responsible_role.css     # Основные стили
└── components/                  # Компоненты
    ├── task_field.php           # Компонент поля в форме задачи
    └── task_list_column.php     # Компонент столбца в списке задач
```

## Описание файлов

### Основные файлы модуля

#### `install.php`
Скрипт установки модуля. Выполняет следующие действия:
- Регистрирует модуль в системе Bitrix24
- Создает кастомное поле для выбора ответственного
- Создает новую роль "Ответственный" с правами наблюдателя
- Создает таблицу базы данных для хранения связей
- Регистрирует обработчики событий

#### `uninstall.php`
Скрипт удаления модуля. Выполняет следующие действия:
- Удаляет регистрацию модуля
- Удаляет кастомное поле
- Удаляет роль "Ответственный"
- Удаляет таблицу базы данных
- Удаляет обработчики событий

#### `module.php`
Файл регистрации модуля в Bitrix24. Содержит:
- Версию модуля
- Описание модуля
- Информацию об авторе
- Права доступа

#### `index.php`
Главный файл модуля. Содержит:
- Класс `ResponsibleRoleModule` для инициализации модуля
- Обработчики событий для работы с задачами
- Методы для работы с ответственными сотрудниками

#### `class.php`
Основной класс помощника `ResponsibleRoleHelper`. Содержит методы:
- `getResponsibleEmployee()` - получить ответственного для задачи
- `getResponsibleEmployees()` - получить всех ответственных
- `setResponsibleEmployee()` - установить ответственного
- `deleteResponsibleEmployee()` - удалить ответственного
- `getUserInfo()` - получить информацию о пользователе
- `getUserFullName()` - получить полное имя пользователя
- `getAllUsers()` - получить список всех пользователей
- `getRoleId()` - получить ID роли
- `isInstalled()` - проверить установку модуля
- `getTasksByResponsibleEmployee()` - получить задачи по ответственному
- `getResponsibleStats()` - получить статистику

#### `events.php`
Обработчики событий. Содержит класс `ResponsibleRoleEventHandler` с методами:
- `onTaskAdd()` - обработка добавления задачи
- `onTaskUpdate()` - обработка обновления задачи
- `onTaskDelete()` - обработка удаления задачи
- `onTaskListDisplay()` - обработка отображения списка задач
- `onTaskDetailDisplay()` - обработка отображения деталей задачи
- `onTaskFilter()` - обработка фильтрации задач
- `onUserDelete()` - обработка удаления пользователя

#### `rest_api.php`
REST API методы. Содержит функции:
- `RestGetResponsibleEmployee()` - получить ответственного
- `RestSetResponsibleEmployee()` - установить ответственного
- `RestGetTasksByResponsible()` - получить задачи по ответственному
- `RestGetResponsibleStats()` - получить статистику
- `RestGetUsersList()` - получить список пользователей
- `RestDeleteResponsibleEmployee()` - удалить ответственного

#### `step.php` и `unstep.php`
HTML страницы для вывода сообщений об успешной установке/удалении модуля.

## База данных

### Таблица `b_responsible_role_mapping`

Таблица для хранения связей между задачами и ответственными сотрудниками.

**Структура:**
```sql
CREATE TABLE b_responsible_role_mapping (
    ID INT AUTO_INCREMENT PRIMARY KEY,
    TASK_ID INT NOT NULL,
    ROLE_ID INT NOT NULL,
    USER_ID INT NOT NULL,
    CREATED DATETIME DEFAULT CURRENT_TIMESTAMP,
    MODIFIED DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY unique_task_role (TASK_ID, ROLE_ID),
    FOREIGN KEY (TASK_ID) REFERENCES b_tasks(ID) ON DELETE CASCADE,
    FOREIGN KEY (ROLE_ID) REFERENCES b_tasks_role(ID) ON DELETE CASCADE,
    FOREIGN KEY (USER_ID) REFERENCES b_user(ID) ON DELETE CASCADE
);
```

**Поля:**
- `ID` - уникальный идентификатор записи
- `TASK_ID` - ID задачи
- `ROLE_ID` - ID роли (всегда "Ответственный")
- `USER_ID` - ID пользователя (ответственный сотрудник)
- `CREATED` - дата создания записи
- `MODIFIED` - дата последнего изменения

## Роль `responsible`

### Таблица `b_tasks_role`

Новая роль "Ответственный" добавляется в таблицу `b_tasks_role`:

**Поля:**
- `CODE` = 'responsible'
- `NAME` = 'Responsible'
- `SORT` = 100

### Права доступа

Права доступа для роли копируются из роли "Observer" и включают:
- Просмотр задач: Да
- Добавление комментариев: Да
- Редактирование задач: Нет
- Удаление задач: Нет

## Кастомное поле

### Поле `UF_RESPONSIBLE_EMPLOYEE`

Кастомное поле для выбора ответственного сотрудника:

**Параметры:**
- `ENTITY_ID` = 'TASKS'
- `FIELD_NAME` = 'UF_RESPONSIBLE_EMPLOYEE'
- `USER_TYPE_ID` = 'enumeration'
- `XML_ID` = 'RESPONSIBLE_EMPLOYEE'
- `MULTIPLE` = 'N' (одно значение)
- `MANDATORY` = 'N' (необязательное)
- `SHOW_FILTER` = 'Y' (показывать в фильтре)
- `SHOW_IN_LIST` = 'Y' (показывать в списке)

## Интеграция с Bitrix24

### События

Модуль регистрирует обработчики для следующих событий:
- `tasks:OnTaskAdd` - при добавлении задачи
- `tasks:OnTaskUpdate` - при обновлении задачи
- `tasks:OnTaskDelete` - при удалении задачи
- `tasks:OnTaskListDisplay` - при отображении списка задач
- `tasks:OnTaskDetailDisplay` - при отображении деталей задачи
- `tasks:OnTaskFilter` - при фильтрации задач
- `main:OnUserDelete` - при удалении пользователя

### REST API

Модуль регистрирует следующие REST API методы:
- `responsible_role.task.getResponsible`
- `responsible_role.task.setResponsible`
- `responsible_role.task.getByResponsible`
- `responsible_role.task.getStats`
- `responsible_role.user.getList`
- `responsible_role.task.deleteResponsible`

## Поток данных

```
Пользователь выбирает ответственного в форме задачи
                    ↓
JavaScript компонент (responsible_role.js)
                    ↓
Форма отправляется на сервер
                    ↓
Обработчик события OnTaskAdd/OnTaskUpdate (events.php)
                    ↓
Класс ResponsibleRoleHelper (class.php)
                    ↓
Таблица b_responsible_role_mapping (база данных)
                    ↓
Информация об ответственном отображается в задаче
```
