# История изменений модуля Responsible Role

## [1.0.0] - 2025-12-15

### Добавлено
- Новая роль "Ответственный" в системе задач Bitrix24
- Кастомное поле `UF_RESPONSIBLE_EMPLOYEE` для выбора ответственного сотрудника
- Таблица базы данных `b_responsible_role_mapping` для хранения связей
- Полный набор REST API методов:
  - `responsible_role.task.getResponsible` - получить ответственного
  - `responsible_role.task.setResponsible` - установить ответственного
  - `responsible_role.task.getByResponsible` - получить задачи по ответственному
  - `responsible_role.task.getStats` - получить статистику
  - `responsible_role.user.getList` - получить список пользователей
  - `responsible_role.task.deleteResponsible` - удалить ответственного
- JavaScript компонент для интерактивного выбора ответственного
- CSS стили для всех компонентов интерфейса
- Компоненты для отображения в форме задачи и списке задач
- Обработчики событий для автоматического управления данными
- Локализация на русский и английский языки
- Полная документация и примеры использования
- Инструкции по установке и удалению модуля

### Особенности
- Права доступа скопированы из роли "Наблюдатель"
- Автоматическое создание и удаление роли при активации/деактивации модуля
- Поддержка фильтрации задач по ответственному сотруднику
- Отображение информации об ответственном в деталях задачи
- Интеграция с REST API Bitrix24
- Полная поддержка мобильных устройств
